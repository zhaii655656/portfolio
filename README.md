# 电商视觉作品集

这是一个无需构建工具的静态作品集网站，包含粒子光效、作品分类筛选、项目画廊以及本地添加作品功能。每组内置项目保留 5 张完整主图，详情素材按原顺序纵向拼接成长图浏览。

## 使用

直接打开 `index.html` 即可浏览。为获得稳定的本地图片存储体验，建议通过本地服务器运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 添加作品

- 网页内：点击“添加作品”，选取多张图片。图片使用 IndexedDB 保存在当前浏览器。
- 永久发布：将图片放入 `assets/works/项目编号/`，然后在 `app.js` 的 `baseProjects` 数组中添加项目配置。

每个内置项目按 `main`、`sku`、`detail` 三类组织。更改 `app.js` 顶部的项目名称、简介和标签即可修改展示文案。

## 个性化

- 网站名与介绍：修改 `index.html`
- 邮箱：搜索 `hello@example.com` 并替换
- 颜色与布局：修改 `styles.css` 顶部的 CSS 变量
